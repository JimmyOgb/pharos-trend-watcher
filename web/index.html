Browser-Local Engine Instance: This interface evaluates trend sequences in your browser with persistent localStorage storage across page reloads. The Python engine runs independently with disk-backed atomic JSON persistence (python scripts/watcher.py); the two environments do not share a database or synchronize automatically.

Requirement 01: Persistent State test_storage.py

Requirement 02: Configurable Threshold test_config.py
Enforces K ≥ 3 observations; configurable direction & interval bounds.

Deterministic IDs prevent duplicate history or repeat trigger events.

Full chronological log rendering exact trigger moment, value, and rationale.
